Выберите тематику, форму и число помещений. Сохраните ссылку: она содержит код и все настройки карты. Смена тематики предлагает подходящий стиль планировки; его можно изменить вручную.

Перетаскивайте карту для перемещения, используйте колесо или +/− для масштаба, Q/E для поворота и Home для общего вида. Нажмите на пол, мини-карту или тип помещения для осмотра.

UVTT — рекомендуемый экспорт для Jumpgate. Он содержит плоскую карту без сетки, контуры стен и свет. В меню страниц Roll20 выберите Create Page → Upload Background и загрузите файл .uvtt. Масштаб задаётся файлом. Поддержка Dynamic Lighting зависит от подписки Roll20. Проверьте свет и стены после импорта; проходы открыты, двери добавляются вручную.

PNG сверху. В ZIP находятся изображения по 70 пикселей на клетку, размеры и координаты каждого фрагмента. Большие карты разбиты на части не более 56 × 56 клеток. Разместите их на слое Map & Background, задайте указанные размеры, квадратную сетку с клеткой 70 px и размер страницы из инструкции.

Изометрический PNG. В ZIP находится вся карта без интерфейса и слоёв мастера. Это изображение для игры без привязки к сетке: отключите сетку в Roll20. Вид сверху удобнее для точных расстояний и Dynamic Lighting. Вращение камеры в просмотре не меняет направление экспорта.

Экспорт для игроков не отмечает тайники и секретные помещения, не показывает маркеры противников и карту сложности. Полный JSON сохраняет данные для мастера и не предназначен для импорта в Roll20. Карта не содержит готового приключения, баланса столкновений или статблоков.

Изометрический просмотр требует WebGL2; генерация, мини-карта и экспорт сверху работают и без него. Алгоритм сохраняет связность помещений и хотя бы один обходной маршрут даже при 0% дополнительных связей.
