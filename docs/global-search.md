# Общий поиск по справочнику — U01

Открывается кнопкой в шапке или `Ctrl+K` / `Cmd+K`. Полная выдача находится на `/search`: запрос, тип результата, редакция и источник сохраняются в URL. Эту ссылку можно отправить другому игроку. Быстрое окно поддерживает стрелки, Enter, Escape и возвращает фокус к элементу, из которого его открыли.

## Содержание

Индекс собирается из опубликованных данных: классы и подклассы, их особенности, виды и варианты, предыстории, черты, заклинания, обычные и магические предметы, глоссарий, божества и навигация по исследованию и путешествиям. Для особенностей сохраняются класс, подкласс и уровень; ссылка выбирает нужный подкласс и ведёт к особенности. Вложенная способность раскрывается через параметр `featurePart`. Для вариантов видов используется параметр `variant`.

Публичные страницы индексируются по явному списку в `src/data/search/catalog.ts`: общие правила, снаряжение, травмы, общие параметры видов, разрешённые материалы, простой, бастионы, FAQ и руководство создания персонажа. HTML предварительно рендерится через Astro: отключённые компоненты прежней эрраты, скрипты и скрытые технические блоки не попадают в индекс. Каталоги допущенных материалов и видов исключены из индекса правил, поскольку их сущности уже представлены отдельными результатами. Старая страница эрраты исключена; правила находятся по тематическим адресам.

По сборке 2026-10-09 — **4 308 записей**: 15 классов, 144 подкласса, 1 302 особенности, 88 видов и вариантов, 60 предысторий, 155 черт, 560 заклинаний, 245 предметов, 507 магических предметов, 151 термин глоссария, 339 божеств, 269 правил и 473 раздела книг. Дополнительно доступны **33 309 фрагментов** четырёх опубликованных в проекте книг: PHB 2014, PHB 2024, DMG 2014 и DMG 2024. Числа проверены по готовым `dist/search-index/catalog.json` и `dist/books/*/search.json`; наличие книги в библиотеке не означает допуск всего её содержимого.

Мастерские правила, страницы кабинета, черновики, пользовательские персонажи и комментарии разработчиков не индексируются. Изменение прав доступа или настройка Supabase для поиска не нужны. При добавлении новой страницы сначала нужно проверить, что её содержимое предназначено для публичного справочника.

## Поиск и источники

Учитываются русские и английские названия из данных, варианты «е/ё», регистр, знаки препинания и распространённые окончания русских слов. Список синонимов и сокращений расположен в `src/utils/siteSearch.ts`, включая КЗ/КД/AC, БМ/PB, СЛ/DC, ПО/CR и названия отдельных заклинаний и состояний. Это управляемый словарь; перевода произвольного запроса и исправления опечаток пока нет.

Точное название располагается выше совпадения в тексте. При одинаковой релевантности публичные правила получают небольшой приоритет, а версия 2024 располагается выше версии 2014. Каждая карточка показывает тип, источник, английское название при наличии, контекст и фрагмент текста.

Редакция берётся из явно заданного источника материала. Для подклассов используется их собственный источник; он не наследуется от класса. Если источник или редакция не указаны, они не придумываются. Добавление `sourceBook` к черте автоматически обновит её результат и фильтры при следующей сборке. Результаты книг не означают допуск всего содержимого книги: действуют опубликованные варианты сайта, каталог разрешённых материалов и общие ограничения Лиги.

## Загрузка и обновление

- `/search-index/manifest.json` — доступные источники, счётчики и ссылки на индексы.
- `/search-index/titles.json` — названия, метаданные и короткие описания для быстрого окна.
- `/search-index/catalog.json` — полные описания опубликованных записей.
- `/books/{id}/search.json` — существующие индексы фрагментов книг; дополнительные копии книг не создаются.

На обычной странице индексы не загружаются до первого запроса. Быстрое окно не скачивает полные описания и тексты книг. Полная страница загружает только книги, подходящие под фильтры; при выборе заклинаний или другого отдельного типа книги не скачиваются. Подготовка индекса и сопоставление запросов выполняются в Web Worker; документы повторно используются в пределах страницы. Для книг после подготовки освобождается исходный JSON. При ошибке части источников остаётся доступная выдача, а повторная попытка заново загружает неудавшиеся источники.

Ввод обрабатывается после паузы 160 мс, устаревшие ответы не заменяют новый запрос. Выдача содержит 40 результатов с кнопкой продолжения, максимум 500; для более широкой выборки нужно уточнить запрос. Быстрое окно показывает восемь результатов и ссылку на полную страницу.

Индексы формируются при `pnpm build`. После изменения данных нужно пересобрать и опубликовать сайт обычным способом. Запросы к индексам используют проверку HTTP-кеша, чтобы стабильные URL обновлялись после публикации. Для новых сборок JavaScript и worker получают новые имена файлов через Vite.

Размер текущего индекса названий — 2,42 МБ, примерно 391 КБ с gzip; полный каталог — 5,40 МБ, примерно 940 КБ с gzip. Фактический размер передачи зависит от сжатия на хостинге. Индексы книг загружаются один раз за посещение страницы; это основной объём первого полного поиска. Измеренный повторный поиск по каталогу на локальном компьютере занимал 18–85 мс, подготовка каталога — около 236 мс; эти значения не являются гарантией для других устройств.

## Проверки

```bash
pnpm test:search
pnpm check:search
pnpm build
```

`src/utils/siteSearch.test.ts` проверяет релевантность, нормализацию, сокращения, фильтры, видимый текст, исключение скрытого содержимого, якоря и безопасность ссылок.

Браузерный сценарий `scripts/check-global-search.mjs` использует тот же локальный Playwright, что проверки книг. Требуются `.book-import/browser/node_modules/playwright-core` и Chromium/Edge; путь браузера можно задать через `BOOK_BROWSER_EXECUTABLE`. Сценарий запускается против `pnpm preview`, адрес задаётся через `SEARCH_PREVIEW_URL` (по умолчанию порт 4323). Проверяются отложенная загрузка, фильтры и история URL, клавиатура, переходы к особенностям, вариантам видов и фрагментам книг, ширины 320–1280, обе темы, отсутствие выполнения введённого HTML и повторная загрузка после ошибки источника. Скриншоты сохраняются в `.book-import/search/`.

Без JavaScript кнопка в шапке ведёт на страницу поиска со ссылками на обычные справочники. Поиск требует браузера с поддержкой Web Worker; отдельного серверного поискового сервиса и новых зависимостей нет.

Проверка 2026-10-07: 7 тестов прошли; Astro-проверка 14 модулей — без ошибок, предупреждений и подсказок; production-сборка — 2 146 страниц. Браузерный сценарий прошёл против готовой сборки, включая все три книги, раскрытие «Договора цепи», обе темы, ширины 320/375/640/700/760/768/1120/1280, ошибки книги и метаданных с последующей успешной повторной загрузкой. В live изменения не публиковались.
