# Боги и покровители — N07

Страница `/deities` доступна через «Справочник → Боги и покровители». Каталог работает без Supabase. Все карточки и публикации сформированы на сервере сборки; без JavaScript остаются доступны раскрывающиеся карточки, источники и поиск браузера.

## Состав каталога

На 5 октября 2026 года каталог [5etools](https://5e.tools/deities.html) содержит 563 публикации. По указанию пользователя исключены 32 записи источника EGtW, обозначенного в данных как `EGW`. Оставшаяся 531 публикация из 12 источников представлена 339 карточками в 20 пантеонах. Повторные публикации в других книгах не исключены из-за совпадения имени с записью EGtW.

Использованы DMG, DSotDQ, ERLW, FRHoF, GoS, MOT, MTF, PHB, SCAG, VGM, VRGR и XDMG. Это все источники, присутствующие в выбранном каталоге после исключения EGtW, включая приключения. Названия книг и даты выпуска сохранены в снимке данных.

Также представлены 42 именованных покровителя из существующего каталога конструктора. Вариант `patron-custom` доступен в конструкторе и описан в памятке, но не считается отдельным именованным существом в справочнике.

Переведены имена, титулы, пантеоны, традиции, сферы влияния, домены и символы. Английские имена и дополнительные имена сохранены для поиска. Для 143 записей с историческими сведениями подготовлены короткие оригинальные русские пересказы; каждый привязан к конкретным имени, пантеону и книге. Полные исторические тексты доступны по ссылке на английский оригинал. Это краткий справочник, а не полный перевод глав книг.

## Архитектура и совместимость

- `src/data/deities/source.json` — снимок фактических полей, происхождение, дата импорта и SHA-256 исходного файла. Содержимое английских глав и изображения не импортируются.
- `scripts/import-deities.mjs` — исключение EGtW, разрешение наследования `_copy`, проверка уникальности и сбор метаданных из списков книг и приключений. Неподдерживаемые модификаторы копий останавливают импорт.
- `src/data/deities/names.ts`, `localization.ts`, `symbols.ts` — русские соответствия. Пропущенные переводы останавливают построение каталога.
- `src/data/deities/briefs.ts` — краткие пересказы с указанием источника; ссылка на отсутствующую публикацию вызывает ошибку.
- `src/data/deities/legacy.ts` — только соответствия прежних 37 имён и идентификаторов для сохранённых персонажей. Справочные характеристики в этом файле не дублируются.
- `src/utils/deities.ts` — группировка публикаций, перевод, ссылки 5etools и выбор справочной публикации.
- `src/data/deities/index.ts` — общий каталог страницы и конструктора. Конструктор импортирует варианты прямо из него; прежний `config/deities.ts` удалён. Список `legacy.ts` сохраняет только соответствия идентификаторов для старых персонажей и не добавляет отдельные варианты в выбор.
- `src/components/characterCreator/config/patrons.ts` — существующий каталог покровителей; страница использует его напрямую.
- `src/utils/deitySearch.ts` — поиск и проверка сочетаний фильтров. `src/scripts/deities.ts` — интерфейс, URL, сброс и раскрытие карточки по якорю.

Группировка учитывает имя **и пантеон**. `Faerûnian` и `Forgotten Realms`, а также `Gnome` и `Gnomish` объединены как обозначения одного пантеона. `St. Cuthbert` и `Cuthbert` объединены внутри Greyhawk. Одноимённые боги разных миров остаются отдельными карточками. Исходное имя пантеона сохраняется для ссылки 5etools.

Публикации показываются от новых к старым. Краткая карточка и конструктор используют самую новую публикацию с указанными доменами; если доменов нет ни в одной, используется самая новая публикация. Источник этих характеристик подписан. Например, новая запись FRHoF может содержать историю, но не домены: тогда справочные поля берутся из SCAG, а отсутствующие поля FRHoF остаются отсутствующими. Данные разных книг не смешиваются в искусственную редакцию. Совместимость механик 2014/2024 по-прежнему описывает N01.

Фильтры книги, домена, мировоззрения и сферы должны совпасть в **одной публикации**. Имя ищется по-русски и по-английски, `ё` и `е` равнозначны. Фильтры хранятся в URL; якорь карточки раскрывает её, при необходимости сбрасывая мешающий фильтр. Конструктор получает все 339 вариантов, фильтр пантеона, английские имена и ссылки на карточки. Старые идентификаторы не меняются, новые выборы сохраняются обычным механизмом черновика.

## Правила Лиги

Страница и общие правила используют один опубликованный текст из `src/data/faithRules.ts`. Добавлен якорь `/general-rules#character-creation`. Выбор покровителя договора не объявляется заменой обязательному выбору божества.

Памятка для собственного варианта предлагает собрать сведения и обсудить их с мастером. Она прямо сообщает, что отдельная процедура утверждения в опубликованных правилах не описана и сохранение черновика не является согласованием. Новые решения Лиги не вводятся; обсуждение блока R и N02–N05 остаётся отложенным.

## Обновление данных

Исходные данные доступны в [публичном репозитории, связанном с 5etools](https://github.com/5etools-mirror-3/5etools-src). Для импорта нужны `data/deities.json`, `data/books.json` и `data/adventures.json`. Прямой запрос к данным на 5e.tools при реализации блокировался Cloudflare; использован публичный репозиторий.

```bash
node scripts/import-deities.mjs path/to/deities.json path/to/books.json path/to/adventures.json
npm run test:deities
npm run build
```

После обновления дополнить переводы новых полей и имён, проверить пантеоны и публикации, обновить краткие справки и дату сверки на странице. Проверки количества в тестах намеренно требуют пересмотра при изменении состава источника. Не удалять и не переименовывать старые ID без миграции сохранённых персонажей.

## Проверки

`npm run test:deities` проверяет полноту импорта, переводы, исключение EGtW, 143 пересказа, 37 прежних ID, разделение пантеонов, наследование VGM, точные внешние ссылки, поиск и согласованность фильтров.

`node scripts/check-deities.mjs` проверяет собранную страницу в Chromium: 381 карточку и 531 публикацию, фильтры и восстановление URL, сброс, якоря, внутренние ссылки, клавиатуру, мобильную ширину, обе темы, чтение без JavaScript и сохранение выбора в конструкторе. Понадобятся `playwright-core`, Chromium и запущенный preview; пути берутся из `.book-import/browser` и `BOOK_BROWSER_EXECUTABLE`. Адрес можно задать через `DEITIES_PREVIEW_URL` (по умолчанию `http://127.0.0.1:4322`). Скриншоты сохраняются в игнорируемом `.book-import/deities`.

Для всех классов доступен полный общий каталог божеств. У Жреца, Друида, Паладина, Монаха и Колдуна выбор обязателен; для остальных его можно оставить пустым или убрать. Варианты «только клятва», «сама природа» и «философская традиция» не заменяют обязательный выбор божества и удалены из списка. При смене класса выбранное божество сохраняется. У Колдуна божество и покровитель договора доступны как отдельные выборы.

Браузерная проверка сравнивает идентификаторы и имена божеств каждого класса со страницей справочника, проверяет отсутствие повторов, сохранение выбора и обязательность для соответствующих классов.

У production-конструктора сохраняется существующее требование авторизации. Без настроенного Supabase его интерфейс проверяется на dev-сервере: укажите его адрес в `DEITIES_WIZARD_PREVIEW_URL`, например `http://127.0.0.1:4323`. Это позволяет проверить production-справочник и локальную интеграцию конструктора одним запуском; проверки входа не отключаются.

Полная сборка проекта обязательна. Проверка TypeScript/Astro новых модулей может выполняться отдельным конфигом, поскольку общая проверка проекта имеет ранее существовавшие ошибки вне N07.

Проверка 2026-10-07 после обновления конструктора: 10 тестов данных прошли; отдельная проверка TypeScript конфигурации классов и её зависимостей — без ошибок. Браузерный сценарий прошёл для всех 15 классов: каталог, отсутствие повторов, обязательность выбора для пяти классов, необязательный пустой выбор и его очистка для остальных, сохранение после перезагрузки. Дополнительно проверено сохранение божества при смене Монах → Плут → Жрец и отсутствие горизонтального переполнения страницы на ширине 375 пикселей. Итоговая production-сборка — 2 146 страниц; в обеих страницах конструктора проверены все 339 божеств у каждого класса. На опубликованный сайт изменения не отправлялись.
