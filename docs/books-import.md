# Подготовка книг и HTML-читалка

Библиотека доступна по `/books/`, первая книга — `/books/phb-2024-ru/`.
Книга игрока 2024 перенесена полностью: все 366 страниц, 85 разделов,
285 таблиц, 123 врезки и статблока, 255 размещений иллюстраций.
Разделы сгруппированы по главам; классы, уровни заклинаний и приложения
имеют отдельные маршруты. Шесть адресов первоначального пилота сохранены.
Длинные перечни заклинаний разделены на части не длиннее семи страниц.

Книга мастера доступна по `/books/dmg-2024-ru/`: неполный исходник заменён полным
переводом. Перенесены все 342 страницы, 128 разделов, 235 таблиц, 263 врезки
и 363 размещения иллюстраций. Доступны все восемь глав, Грейхок, глоссарий лора,
18 карт и восемь листов отслеживания. Печатная нумерация совпадает с номером
страницы PDF; содержание содержит действующие ссылки.
Карты и бланки сохранены как изображения с русскими подписями и открываются
в полном размере. Их текст также доступен в раскрываемом блоке и поиске.
Позиция чтения содержит хеш исходника: устаревшая позиция прежнего издания
не будет направлять читателя к другой странице новой книги.

Книга игрока 2014 доступна отдельно по `/books/phb-2014-ru/`: все 331 страница
русского PDF, 115 разделов, 156 таблиц, расы, двенадцать классов, предыстории, правила,
заклинания, приложения, словари и листы персонажа. Для страниц основного текста
печатный номер на единицу меньше номера PDF; ссылки содержания учитывают сдвиг.

Книга мастера 2014 доступна по `/books/dmg-2014-ru/`: все 322 страницы русского
PDF, 145 разделов и 301 таблица. Перенесены девять глав, магические предметы,
дополнительные правила, случайные подземелья, списки чудовищ и приложения с картами.
Печатные номера основного текста на единицу меньше номеров PDF; ссылки содержания
ведут на соответствующие страницы HTML-книги. Карты сохранены в полном размере,
подписи доступны в раскрываемом блоке и поиске. Новая книга также подключается
к существующему общему поиску сайта при сборке.

## Что загружается на сайте

Astro собирает обычные HTML-страницы из подготовленного JSON. Каждый раздел
имеет отдельный URL. Текст, таблицы и оглавление доступны без JavaScript.
JavaScript добавляет поиск, размер текста и локальное сохранение места чтения.
Индекс поиска одной книги загружается только после ввода запроса.
Заголовки правил и заклинаний предшествуют упоминаниям в таблицах.
Печатный список заклинаний на странице 229 содержит ссылки на страницы
этого же HTML-издания. Указатели существ на странице 332 и правил на странице
348 также содержат ссылки. Внутри раздела есть раскрываемый список заголовков.
Иллюстрации сохраняются в WebP, большие изображения имеют вариант шириной 640 px
и загружаются через `srcset` и `loading="lazy"`. Общий CSS использует системные
шрифты, светлую и тёмную темы сайта.

PDF используется исключительно локальным импортёром. Для сборки и чтения
не нужны Python, PDF, Supabase или отдельное файловое хранилище.
Исходные PDF, виртуальное окружение и промежуточные результаты исключены из Git.

## Файлы

- `scripts/books/import_book.py` — локальное извлечение и подготовка структуры.
- `scripts/books/phb-2024-ru.json` — описание книги, выбранные страницы и проверенные области врезок.
- `scripts/books/phb-2014-ru.json` — оформление и состав русского перевода Книги игрока 2014.
- `scripts/books/dmg-2024-ru.json` — профиль шрифтов, таблиц и состава Книги мастера.
- `scripts/books/dmg-2014-ru.json` — отдельный профиль русского перевода Книги мастера 2014.
- `src/data/books/<book>/book.json` — каталог и перечень доступных разделов.
- `src/data/books/<book>/sections/*.json` — содержимое разделов.
- `public/images/books/<book>/*.webp` — подготовленные иллюстрации.
- `public/books/<book>/search.json` — отдельный индекс поиска книги.
- `.book-import/<book>/layout.json` — текстовые блоки с координатами и шрифтами.
- `.book-import/<book>/outline.json` — полное исходное оглавление.
- `.book-import/<book>/report.json` — статистика и список объединённых переносов.
- `.book-import/<book>/pages/*.json` — контрольные точки отдельных страниц.
- `.book-import/<book>/audit.json` — сверка покрытия, чисел, ссылок и таблиц.
- `scripts/books/<book>.edits.json` — необязательные редакторские замены страниц.

У блоков есть страница исходника и якорь, например
`/books/phb-2024-ru/cantrips/#p230-2`. Страница также имеет якорь `#page-230`.
Номера страниц относятся к конкретному русскому переводу. Например, «Брызги
кислоты» здесь на странице 230, тогда как существующий справочник указывает 239.
Связи справочника с книгой нужно проверять отдельно; они пока не переписаны.

## Повторить импорт на Windows

```powershell
python -m venv .venv-books
.\.venv-books\Scripts\python.exe -m pip install -r scripts/books/requirements.txt
.\.venv-books\Scripts\python.exe scripts/books/import_book.py --config scripts/books/phb-2024-ru.json
```

Профиль активной книги обязательно указывается через `--config`; запуск без
него завершается до открытия PDF. Исходник берётся только из этого профиля;
его путь можно заменить через `--source`. Обхода PDF остальных книг и пакетного
переимпорта нет, в том числе после изменения алгоритмов. Кеш, разделы, изображения
и поисковый индекс записываются только в каталоги выбранной книги.
Сборка Astro использует готовый JSON других книг и не извлекает их PDF.
На Linux/macOS соответствующий Python находится в `.venv-books/bin/python`.

Импорт и сверка Книги мастера:

```powershell
.\.venv-books\Scripts\python.exe scripts/books/import_book.py --config scripts/books/dmg-2024-ru.json
.\.venv-books\Scripts\python.exe scripts/books/audit_book.py --config scripts/books/dmg-2024-ru.json
```

Импорт и сверка Книги игрока 2014:

```powershell
.\.venv-books\Scripts\python.exe scripts/books/import_book.py --config scripts/books/phb-2014-ru.json
.\.venv-books\Scripts\python.exe scripts/books/audit_book.py --config scripts/books/phb-2014-ru.json
```

Импорт и сверка Книги мастера 2014:

```powershell
.\.venv-books\Scripts\python.exe scripts/books/import_book.py --config scripts/books/dmg-2014-ru.json
.\.venv-books\Scripts\python.exe scripts/books/audit_book.py --config scripts/books/dmg-2014-ru.json
```

Сверка также требует явный профиль и читает подготовленные контрольные точки
только этой книги; она не запускает извлечение остальных PDF.

Импорт сохраняет контрольную точку после каждой страницы и сообщает прогресс
каждые десять страниц. После остановки достаточно повторить ту же команду:
страницы с неизменным PDF, профилем и версией обработки будут взяты из кеша.
Наличие непустых файлов иллюстраций проверяется перед использованием кеша.
Изменение исходника или профиля автоматически обновляет нужные страницы.

Готовые разделы JSON генерируются заново: прямые исправления в них будут
перезаписаны. Храните исправления в профиле/импортёре либо в отдельном файле
`phb-2024-ru.edits.json`. Для каждой заменяемой страницы этот файл содержит
`expectedSha256` и массив `blocks` в словаре `pages`. Хеш вычисляется как
SHA-256 от `json.dumps(checkpoint['page'], ensure_ascii=False, sort_keys=True)`
в UTF-8; контрольная точка находится в `.book-import/<book>/pages/<page>.json`.
Если исходная структура изменилась, импорт остановится с требованием сверить
редакторскую замену; исправления не потеряются молча.

`--prepare-only` пересобирает разделы из готовых контрольных точек, без
извлечения страниц и перекодирования изображений; при устаревшем кеше команда
останавливается. `--force` повторяет извлечение всех выбранных страниц.
Импортёр удаляет только свои неиспользуемые WebP с именами
`page-<номер>-<хеш>.webp` внутри проверенного каталога этой книги, а после успешной
замены состава — устаревшие разделы JSON с совпадающим идентификатором книги.
Резервная копия пилота находится в `.book-import/backups/pilot-before-full/`.
Подготовленная неполная Книга мастера сохранена локально в
`.book-import/backups/dmg-partial-before-replacement/`.

Замеры в текущем окружении: полный проход с подготовкой иллюстраций — около
204 секунд после оптимизации WebP, повторное извлечение с готовыми изображениями
— около 124 секунд, пересборка из всех 366 контрольных точек — 4–5 секунд.
Это время машинной обработки; настройка профиля, сверка и исправления в него
не входят. Для другой книги потребуется собственный замер.

Для полного PDF Книги мастера первый проход занял около шести минут;
повторное извлечение с готовыми WebP — около 2,5 минуты.
Пересборка из контрольных точек с обновлением одной страницы занимает около шести секунд.
Иллюстрации с вариантами для небольших экранов занимают примерно 46,4 МиБ;
поисковый индекс — около 3,4 МиБ и скачивается только при поиске в этой книге.
Эти файлы загружаются по мере чтения, вся книга при открытии не скачивается.
Это локальные замеры
машинной обработки, без времени настройки и ручной сверки.

Для PHB 2014 первичное извлечение с подготовкой изображений заняло около четырёх
минут, повторное извлечение с готовыми WebP — около 80 секунд. Изображения занимают
примерно 38,4 МиБ, отдельный индекс поиска — около 4,4 МиБ. Настройка и выборочная
сверка оформления в эти замеры не входят.

Первичный машинный проход DMG 2014 занял около 3 минут 15 секунд; обновление
одной страницы из контрольных точек — около четырёх секунд. Иллюстрации занимают
примерно 51 МиБ, отдельный индекс поиска — около 3,3 МиБ. Настройка профиля,
ручная сверка сложных таблиц и проверки сайта в эти замеры не входят.

## Как извлекается структура

Импортёр читает каждую колонку сверху вниз; определяет колонку по центру
текстового блока, учитывая смещение левого края. Широкие таблицы и заголовки
разделяют страницу на полосы. Профиль страницы 229 задаёт четыре колонки.
`referenceRegions` в профилях страниц 332 и 348 задаёт две узкие колонки
внутри одной основной колонки для печатных указателей.
Импортёр распознаёт заголовки по шрифту и
размеру, сохраняет жирное начертание, курсив и цвета реплик. Текстовые строки
собираются в абзацы, печатные переносы объединяются. Числовые диапазоны и
распознанные составные слова сохраняют дефисы.

Таблицы извлекаются как строки и ячейки. Однострочные рамки с репликами не
считаются таблицами. Нумерация списков сохраняется, включая продолжение после
поясняющего маркированного списка. Фоновые плитки отфильтровываются по повторяющейся
геометрии. Иллюстрации извлекаются отдельно, с учётом масок прозрачности.
Врезки определяются проверенными прямоугольниками из профиля страницы и
известными фонами примечаний/рамками статблоков этого издания.
Таблицы внутри статблоков сохраняются внутри соответствующей врезки.
Для 66 компактных сеток характеристик отдельно восстановлены шесть строк
и четыре столбца: характеристика, значение, модификатор и спасбросок.
Бонус спасброска берётся из PDF отдельно, а не вычисляется из модификатора.
Текст поверх иллюстрации сохраняется как текст; автоматически в подпись
переносятся только небольшие строки авторства. Прозрачность иллюстраций
сохраняется, включая корректные цвета краёв после снятия premultiplied alpha.

Отличия полного PDF Книги мастера включаются её профилем: `deduplicateGlyphs`
убирает дублирующие символы ссылок и соединяет фрагменты одной строки;
`externalTableHeaders` восстанавливает заголовки вне табличной сетки.
`referenceHeadingLinks` делает заголовки глав печатного содержания ссылками,
включая строки, где номер страницы сразу следует за точками.
`shadedTextTables` извлекает таблицы по фону строк, когда обычная сетка отсутствует;
при наличии сетки используются её точные границы ячеек. Парные таблицы бросков
объединяются по одинаковым заголовкам. `calloutFills` задаёт проверенный цвет
сиреневых примечаний, повторяющиеся бумажные фоны исключены через `ignoreImages`.
`renderIllustration` применяется к обложкам, страницам-иллюстрациям, картам и бланкам: сохраняет графику
вместе с русскими подписями; основной текст и таблицы остаются HTML.
Маски прозрачности с другим разрешением приводятся к размеру иллюстрации.
Для других изданий предусмотрены `headingFonts`, `softHyphenWraps`, `dropCaps`,
`rejectSparseTables`, `skipTables` и `usePdfPageLabels`.
`coverageLabel` и `sourceNote` позволяют явно описать неполное издание.

Для Книги игрока 2014 применяются `headingSizes` и `headingColors`: имена
встроенных шрифтов в этом PDF меняются от страницы к странице. `drawnTextTables`
использует цветные фоны и координаты слов вместо ложных сеток декоративных рамок.
Границы отдельных ячеек и объединение строк проверены на таблицах развития классов,
ячеек заклинаний, опыта и характеристик. `classicAbilityTables` сохраняет шесть
характеристик и исходные модификаторы существ, без вычисления новых значений.
`initialLetters` восстанавливает проверенные буквицы, которые в исходнике являются
рисунками. `referenceBaselineRows` выравнивает содержание по базовой линии текста,
`referencePageOffset` и `printedPageOffset` учитывают отличие печатной нумерации.
В описаниях заклинаний `paragraphStartPatterns` выделяет параметры в отдельные
строки, а `paragraphGap` отделяет описание от многострочных значений параметров.

Для DMG 2014 профиль включает `tableStripeRows`, `tableCellColumns` и
`tableBodyFontMax`: цветные полосы задают логические строки, границы ячеек —
столбцы, а следующий обычный абзац остаётся вне таблицы. Переносы названий
и значений сохраняются внутри одной строки. `tableRestartPatterns` разделяет
соседние таблицы; `textTableColumns` задаёт проверенные границы неоднозначных
столбцов. На страницах PDF 91, 110 и 299–302 плотные таблицы случайных результатов
имеют проверенные области `textTableRegions` и `textTableRegionsOnly`;
`tableHeaderLookback` ограничивает область заголовка. На странице 110
сохраняется и отдельная таблица с кеглем 9 pt. `challengeListColumns`
отделяет длинные списки существ от напечатанной пары «ПО (опыт)».
Эти параметры действуют только в профиле DMG 2014; другие книги не переизвлекаются.

Профиль ориентирован на оформление этой книги. Для других изданий потребуется
сверка колонок, шрифтов, таблиц, врезок и порядка чтения. Автоматический импорт
не гарантирует редакторское качество каждой страницы. Отчёт помогает
найти спорные места, но не заменяет сверку с PDF.
Статус `complete` означает полное покрытие исходных страниц. Для этой книги
проведены автоматические проверки исходных страниц книг и выборочная визуальная сверка
разных типов оформления; построчная редакторская вычитка всех страниц
не выполнена. Текст перевода не переписывался по смыслу.

## Проверки

```powershell
$env:ASTRO_TELEMETRY_DISABLED = '1'
npm run check:books
npm run test:books
.\.venv-books\Scripts\python.exe -m unittest discover -s scripts/books -p 'test_*.py'
.\.venv-books\Scripts\python.exe scripts/books/audit_book.py --config scripts/books/phb-2024-ru.json
npm run build
npm run preview -- --host 127.0.0.1 --port 4321
```

При работе с одной книгой проверку её подготовленных страниц можно ограничить:

```powershell
$env:BOOK_TEST_ID = 'phb-2014-ru'
npm run test:books
```

Эта проверка использует только подготовленные JSON и WebP и не извлекает PDF.
Без `BOOK_TEST_ID` проверяются подготовленные страницы всех книг.

При импорте PHB 2014 контрольные суммы и время изменения 1702 существовавших
файлов книг 2024 года сверены до и после: их данные, изображения и кеш не менялись.
Общая проверка подготовленной библиотеки обнаружила 168 ранее отсутствовавших
миниатюр DMG 2024; в рамках работы с PHB 2014 её PDF не переимпортировался.
Для восстановления миниатюр следует отдельно выбрать профиль DMG.

При добавлении DMG 2014 тем же способом сверены 2249 файлов трёх неактивных
книг: PHB 2014, PHB 2024 и DMG 2024. Их содержимое и время изменения сохранены;
извлечение выполнялось только из `trio_2014/DMG.pdf`.

Отдельная проверка типов библиотеки нужна, поскольку общий `npm run check`
в текущем проекте сообщает о существующих ошибках в других разделах.
`check:books` проверяет новый код и не заменяет общую проверку сайта.

Необязательная браузерная проверка (нужен установленный Chrome/Edge):

```powershell
npm install --prefix .book-import/browser --no-save --package-lock=false playwright-core
node scripts/books/check_browser.mjs
node scripts/books/check_library_browser.mjs dmg-2024-ru
node scripts/books/check_library_browser.mjs phb-2014-ru
node scripts/books/check_library_browser.mjs dmg-2014-ru
```

При необходимости задайте `BOOK_BROWSER_EXECUTABLE` и `BOOK_PREVIEW_URL`.
Проверяются все 87 маршрутов книги и библиотеки, поиск и подсветка, сохранение позиции и размера
текста, мобильная ширина 360 px, доступность чтения без JavaScript, отсутствие
запросов PDF и отложенная загрузка поискового индекса. Отчёт и скриншоты находятся
в `.book-import/`. Измерения скорости на localhost не являются оценкой скорости
Netlify или медленного мобильного соединения.
Проверка Книги мастера обходит все 130 маршрутов библиотеки/книги на компьютере
и все 128 разделов на телефоне, проверяет номера страниц, поиск, ссылки из
содержания, открытие карты, сброс устаревшей позиции и независимость позиции
чтения разных книг. Её отчёт и скриншоты
находятся в `.book-import/dmg-2024-ru/`. Код аргумента можно заменить для другой книги.
Проверка DMG 2014 обходит 147 маршрутов библиотеки/книги на компьютере и 145
разделов на телефоне; дополнительно проверяет содержание, печатные номера,
поиск магического предмета, таблицу сложности столкновений и карту.
Отчёты и скриншоты находятся в `.book-import/dmg-2014-ru/`.

## Следующее расширение

Для каждой новой книги создаётся профиль с другим `id`;
каталог, маршруты и манифест общего поиска подхватят её подготовленные данные
при сборке. Тексты книг хранятся в отдельных поисковых индексах и загружаются
по запросу; добавление новой книги не запускает повторное извлечение остальных PDF.
