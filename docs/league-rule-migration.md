# Перенос правил прежней эрраты (U03)

Дата: 2026-10-09. Реализовано и проверено в проекте; в live не публиковалось.

Пользователь уточнил, что описания сайта уже адаптированы для открытого стола. Эррата осталась от прошлого сезона, когда правила применялись поверх чужих справочников и книг, и не является полным перечнем отличий сайта от оригиналов. Поэтому U03 переносит действующие общие правила по темам, а полный аудит отличий всех карточек от книг остаётся самостоятельной задачей.

## Сверка опубликованных блоков

До переноса на странице подключались шесть блоков. Остальные компоненты находились в комментарии и не вводятся в действие этой задачей.

| Блок | Основной адрес | Результат сверки и связь с карточками |
| --- | --- | --- |
| Ограничения оружия | `/rules/equipment#weapon-restrictions`, `/character-guide#starting-weapons` | В описаниях пистоля и мушкета перечислены параметры оружия; отдельные допуск и запрет на старте сохраняются в общих правилах. Обе карточки имеют ссылки и видимые пояснения; из правил есть обратные ссылки. Обычный длинный лук не отмечен как большой. |
| Возраст, рост и вес видов | `/races#race-attributes` | Сохранены условные значения только при отсутствии собственных сведений вида. Из заголовка каждой карточки и руководства создания героя есть ссылка. Данные видов массово не подменяются значениями по умолчанию. |
| Контейнеры на персонаже | `/rules/equipment#containers` | Это ограничение надетых контейнеров быстрого доступа; вместимость предметов в исходных карточках не переписана. Проверены рюкзак, бурдюк, колчан, сумка, футляры для болтов и карт/свитков, сумка хранения и колчан Элонны. Из исследования оставлены ссылки вместо повторного текста. |
| Увеличенное оружие | `/rules/equipment#oversized-weapons` | Сохранены множители костей и веса ×2/×3/×4, учёта в пуле наград ×3/×6/×12, ограничения получения и условие телосложения. Добавлены связи с семью прямо перечисленными видами, ссылки из правил ОС и создания героя. Обычные виды оружия и эффекты увеличения не получают правило автоматически. |
| Травмы | `/rules/injuries#injuries` | Сохранены все пять условий Лиги. Последствия доступны по ссылке на имеющуюся книгу DMG 2014; исходные книжные условия получения травм не выданы за условия Лиги. Текст не объявляет травму автоматической при каждом падении или каждом крите и не отменяет опциональность. |
| Расходуемые компоненты | `/general-rules#consumable-components` | Дополняет существующее правило о приобретении стоимостных компонентов, а не заменяет его. Применимость зависит от заклинания и исключения в описании предмета. Проверены прямо названные семейства зачарованного оружия, доспехов и посохов; общей ссылкой из каталога охвачены остальные предметы. |

## Границы и обнаруженные неоднозначности

- В правиле увеличенного оружия перечислены орки, гиффы, кентавры и локсодоны, но названия и наличие соответствующей особенности в текущих карточках различаются: у орка нет «Мощного телосложения», у кентавра оно названо «Лошадиное телосложение», у локсодона — «Крупное телосложение», у гиффа используется иное описание. Перенос не добавляет им отсутствующую способность. Ссылка в карточке напоминает об условии исходного правила; уточнение применимости требует отдельного решения по механике.
- Таблица роста и веса сохранена в исходной форме, включая запись модификатора роста. Новые формулы расчёта, автоматическая генерация размеров или новые пределы возраста не введены.
- Связи расходуемых компонентов не выводятся автоматически из слов «заряд» или «заклинание»: у конкретных предметов могут быть исключения. Перечень обратных ссылок показывает проверенные связи, а не все возможные сочетания предметов и заклинаний.
- Метка встроенной адаптации поддерживается, но текущие описания не получают её без подтверждённого сравнения с источником. Отсутствие метки не означает совпадение с книгой.
- Неопубликованные компоненты прежней эрраты (`RaceLineages`, `IllegalGoods`, `IllegalGoodsPrices`, `LegendaryItems`, `Tattoos`) остаются отключёнными. Их наличие в репозитории не означает действие правил.

## Адреса и единый текст

Реестр `src/data/leagueRules.ts` задаёт стабильные ID и текущие адреса. Активные компоненты перенесены из каталога `errata` в тематические каталоги; старые копии удалены. Страница `/heroes-league-errata` содержит только указатель: известные якоря автоматически переводят к соответствующим правилам, а без JavaScript доступны обычные ссылки. Для неё задан `noindex`; из меню и внутреннего поиска она исключена. Поиск индексирует правила по новым адресам.

Файл связей `src/data/materialAnnotations.ts` используется карточками, раскрываемыми каталогами, конструктором и обратными ссылками. Поле `errata` оставлено внутренним именем для совместимости; публичные метки различают адаптации, уже учтённые в описании, и отдельные ограничения. Гайд: [маркировка материалов](material-marking.md).

## Выполненные проверки

- `npm run test:materials`, `npm run test:exploration`, `npm run test:search`: 15 + 6 + 7 = 28 тестов, все прошли. Сценарий адаптации проверяет, что изменение обозначено как уже включённое в описание и отличается от отдельного ограничения; адаптация без пояснения отклоняется.
- Astro check по затронутым модулям: 30 файлов, 0 ошибок и 0 предупреждений; 2 существующие подсказки JSDoc в каталоге видов. Проверка поиска также завершилась без ошибок и предупреждений.
- `npm run build`: 2 295 страниц, сборка успешна.
- `node scripts/check-league-rules.mjs`: 44 материала с проверенными связями, пять адресов правил из этих связей; все семь адресов реестра доступны и индексируются, известные старые якоря перенаправляют, неизвестный якорь сохраняет указатель. Проверены обратные ссылки, внутренние ссылки и книжные якоря, фильтр каталога, отсутствие старой страницы в поиске, обе темы, ширина 375 px, отступ якорей под шапкой и чтение без JavaScript. Снимки: `.book-import/league-rules`.
- `node scripts/check-material-metadata.mjs`: девять типов карточек, переключение подклассов и вариантов видов, раскрываемые каталоги, ссылки, темы и чтение без JavaScript. Отдельный браузерный сценарий конструктора в этой задаче не запускался; его общий рендер метаданных проверен модульно.
- `node scripts/check-exploration.mjs`: десять тем, 36 фрагментов и 64 связанные ссылки; поиск, клавиатура, URL, якоря, мобильные таблицы, темы и чтение без JavaScript.

В каталоге исправлена сериализация `data-has-errata`: явная строка `true`/`false` сохраняет отдельный признак правила для фильтра при одновременной замене версии. В затронутом руководстве создания героя исправлены незакрытые теги списков и абзацев, выявленные проверкой типов; содержание правил сохранено. Пользовательский патчноут обновлён в текущем блоке «Не опубликовано».
