# Разрешённые материалы и совместимость редакций

Страница: `/allowed-materials`. В меню: «Правила → Разрешённые материалы». Доступна без аккаунта и Supabase.

## Подтверждённый порядок допуска

2026-10-05 пользователь подтвердил два правила для N01:

- Все опубликованные варианты разрешены в редакции сайта с учётом общих правил и ограничений Лиги. Формулировка уточнена 2026-10-09: описания уже могут включать адаптации, а прежняя эррата не является полным перечнем отличий от книг.
- Версия 2024 имеет приоритет; старую используют при отсутствии новой.

Допуск относится к опубликованным вариантам сайта. Другой материал из той же книги вводится по действующим общим правилам через совещание мастеров. На странице собраны ссылки на опубликованные ограничения оружия, травм, контейнеров и расходуемых компонентов; тексты исходных правил не менялись.

## Откуда берётся каталог

`src/data/materials.ts` собирает действующие экспортируемые списки классов, подклассов, видов и их вариантов, предысторий, черт, заклинаний, обычных и магических предметов. Файлы старых или отключённых вариантов, не включённые в эти списки, не получают допуск через каталог.

Источник и редакция определяются из поля источника. Разные написания кода с пробелами, апострофами и разным регистром объединяются. Метки `14` и `24` обозначают редакцию правил. Код без такой метки сохраняется с неуказанной редакцией: например, `DMG` и `DMG24` не объединяются автоматически.

У подклассов источник читается из собственного `sourceBook`, а при отсутствии поля — из конца английского названия. Источник класса не наследуется, поскольку класс 2024 может включать подкласс 2014. У черт поддерживается необязательное поле `sourceBook`; пока оно не заполнено, они остаются разрешёнными, с неуказанным источником и редакцией. Ошибочные или неоднозначные коды вроде `PHP24` не исправляются по догадке.

Варианты видов открываются сразу через параметр `variant`, подклассы — через параметр `subclass`. Их собственные метаданные отображаются при переключении селектора; без JavaScript источники вариантов доступны в отдельном раскрываемом блоке.

## Сравнение версий

`src/utils/materialCatalog.ts` сравнивает английское имя и тип материала. Для подклассов и вариантов вида учитывается родитель. Если есть единственная совпадающая версия 2024, запись 2014 получает отметку «Заменён новой версией» и ссылку на новую запись. Неуказанная редакция не считается старой или новой автоматически; при нескольких кандидатах замена требует явной связи.

Чтобы будущие варианты корректно сравнивались, сохраняйте одинаковое английское имя одной сущности, собственный источник и стабильный ID. Явные замены и связи с тематическими правилами Лиги задаются в `src/data/materialAnnotations.ts`: [гайд с примерами](material-marking.md). Метки различают уже встроенную адаптацию и отдельное ограничение; пояснения видны в карточках. Связи используются карточками, конструктором, каталогом и обратными ссылками. Они не теряются при замене: материал можно найти по обоим фильтрам. Отсутствие метки не подтверждает совпадение с книгой. Перенос прежней эрраты описан в [разборе U03](league-rule-migration.md).

## Как добавлять источники черт

Модель: `src/types/feat.ts`. Записи: `src/data/feats/index.ts`. Используйте `sourceBook` отдельно от `nameEn`, по той же схеме, что у классов и предысторий. Пример формата (источник нужно сверить с конкретным текстом черты):

```ts
{
  id: 'existing-feat-id',
  name: 'Название черты',
  nameEn: 'Feat Name',
  sourceBook: 'PHB`24',
  type: 'general',
  effects: ['Текст эффекта'],
}
```

Суффикс `14` или `24` означает редакцию правил 2014 или 2024, а не год выхода книги. Например, книгу, вышедшую в 2017 году для правил 2014, следует помечать редакцией `14`. Если требуется библиографический год издания, добавьте для него отдельное поле; текущий обработчик не выводит редакцию из произвольного года.

После заполнения поля и пересборки сайта черта автоматически попадёт в соответствующую группу источника в `/allowed-materials`, поиск по коду книги и фильтр редакции. Правило приоритета 2024 также применяется автоматически к совпадающим английским названиям. Отдельные поля редакции и допуска в самой черте не нужны: их вычисляет общий каталог по источнику и политике Лиги.

Заполняя источник существующей черты, сохраняйте её `id` и названия: ссылки и выборы персонажей используют ID. Если публикуются два разных текста черты для 2014 и 2024, заведите отдельные записи с разными ID и одинаковым `nameEn`; существующий ID остаётся у существующего текста. Одного изменения источника недостаточно для публикации второй версии.

Конструктор сохраняет `sourceBook` в списках черт происхождения, общих черт для особого происхождения, специальных черт предысторий и боевых стилей. Поле `source` у выбора черты в конструкторе имеет другое назначение: оно показывает, чем выдана черта (видом или предысторией), поэтому для книги используется именно `sourceBook`. Источник, редакция и отметки исключений отображаются рядом с материалом через общий каталог N01.

Неизвестный источник можно не указывать. Существующие записи поддерживаются без массового заполнения; источник не угадывается по типу черты или предыстории, которая её выдаёт.

## Поиск и проверка

Поиск охватывает русское и английское название, родителя и источник. Фильтры: редакция, тип материала и допуск. Поиск и фильтры записываются в URL через `q`, `edition`, `kind`, `status`; ссылку можно сохранить или передать. Без JavaScript каталог остаётся доступен через раскрываемые списки источников.

Проверки:

- `npm run test:materials` — источники, сравнение версий, ограничения оружия и поиск.
- `npm run build` — production-сборка.
- `node scripts/check-materials.mjs` — браузерная проверка при наличии локального Playwright из инструментов книг и готового `dist`. Адрес задаётся через `MATERIALS_PREVIEW_URL`, по умолчанию `http://127.0.0.1:4321`. Проверяются фильтры, восстановление URL, ссылки, мобильный интерфейс, темы и чтение без JavaScript.
- `node scripts/check-material-metadata.mjs` — источники и отметки в карточках всех типов, раскрываемых справочниках, ссылки и якоря, темы, мобильный вид и отсутствие JavaScript. `MATERIALS_PREVIEW_URL` по умолчанию `http://127.0.0.1:4322`; при заданном `MATERIALS_WIZARD_PREVIEW_URL` дополнительно проверяется конструктор на dev-сервере с локальным обходом авторизации. Если опубликованных пар старой/новой версии нет, связи замены проверяются модульными тестами.

Блок R отложен по решению пользователя. Эта страница не меняет мастерские правила, их формулы или порядок разрешения конфликтов.
